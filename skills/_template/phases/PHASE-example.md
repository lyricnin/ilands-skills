# Fase: ejemplo

Este archivo es el patrón para skills largos: el `SKILL.md` decide el camino y
cada fase se abre solo cuando toca. Los skills de una sola tanda no lo necesitan
y se puede borrar la carpeta `phases/`.

## Qué entra

Qué necesito al abrir esta fase: un archivo, un id, un resultado previo.

## Qué sale

Qué deja listo para la fase siguiente, con nombre de archivo o de campo.

## Cómo se hace

Pasos, comandos, y el criterio para saber que quedó bien.

## Cuándo se abandona

La condición que dice "esto no va" y qué hacer con lo que ya se gastó.
